Fyltrix per-user installation

Launch Fyltrix.exe in this installation's root directory. Keep the versioned payload directories with it.
Settings and saved data are kept in %AppData%\Fyltrix; caches in %LocalAppData%\Fyltrix. Settings from 0.1.10 and earlier (%AppData%\FileLens) are copied there on first start; that folder is left unchanged.
Uninstall never deletes those data stores. It uses the installer log plus the owner-bound updater file inventory. Unknown files and modified updater-owned files remain.

Close this installed copy before a manual upgrade or uninstall. Setup never force-closes applications.
Older payloads are retained. The separate explicit update backend validates copied-profile health before switching versions.
An interrupted update journal blocks startup and installer changes until authenticated recovery completes; see docs/APPLY_AND_RECOVERY.md in the source repository.
WebView2 Runtime and optional codecs/preview handlers are still required separately.

Sandbox installers are for isolated testing only. They are never launched automatically.
The application payload still uses its established data locations; tests must redirect those locations before launch.
This build does not enable automatic update checks or installation.
