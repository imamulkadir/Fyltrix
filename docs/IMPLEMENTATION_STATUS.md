## NOTIFICATION PLAN STAGE 3 (2026-11-01): optional installation on safe normal exit

It reuses work/dialog/sharing/automation guards, rechecks the opt-in before handover and respects later vetoes. Duplicate close requests cannot start another preparation; a failed attempt keeps the app open and the next close exits without retrying. Background-sharing/tray exit, Windows SessionEnding and previous-attempt evidence skip exit installation. ## Known limitations (for the final report)

- Encrypted archive creation: AES-256 ZIP only, through Windows tar.exe (the password goes on tar's command line). 7z creation needs a tar.exe with the 7zip writer (probed at runtime). RAR is extract-only.
- SharpCompress can't decrypt streamed encrypted ZIP entries; these fall back to tar.exe staging (size limit checked from the central directory).
- Folder sizes count hard links per link. Tags don't follow moves made outside Fyltrix ("Clean up tags of missing files" exists). Tags aren't copied with copies.
- FLV usually can't play: Media Foundation has no FLV source. HEVC/AV1 depend on the installed Windows video extensions.
- PDF: new files from encrypted PDFs are saved unencrypted; any edit invalidates signatures (the UI warns); some bookmarks pointing at removed pages are dropped.
- Automation runs only while Fyltrix is open. Sharing is plain HTTP (the warning is shown); stopping happens on window close or expiry.
- WebView2 must be installed (it ships with Edge on Windows 10/11). The preview engine starts when a preview pane is shown and is released 30 s after the pane is hidden, so showing it again then takes ~1 s.
- The theme (Dark/Light/System) applies at the next start. Fyltrix is a single-colour-scheme app until then.
- Compare shows PDFs page by page as images (so both sides scroll together); text in them can't be selected there. Images, PowerPoint and video don't sync.
- Per-folder views and tags follow renames made in Fyltrix; folders moved or renamed elsewhere get the default view (stale entries are pruned when there are more than 5 000).
- Search stops at 100 000 results (a guard against runaway whole-drive searches; the status bar says so).
- "Open with…" placement depends on Windows (SHOpenWithDialog with Fyltrix as owner); not covered by an automated test.
- No search history is kept, so there is nothing to clear (Settings says so).
